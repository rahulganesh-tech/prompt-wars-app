## 🎯 1. Problem Statement & Target User

### Problem Statement (Official Hackathon Track):
> *"Build an AI tool that helps a first-time woman user in rural India — no English, no tech background, no one to ask — independently access one essential government service/scheme through voice or simple text, in her own language, with zero prior digital knowledge required."*

### Target User Persona:
- **Name:** Lakshmi (42 years old, rural Tamil Nadu)
- **Background:** Agricultural laborer and homemaker; first-time smartphone user.
- **Language:** Speaks and understands spoken Tamil (`தமிழ்`) only; no English comprehension.
- **Tech Familiarity:** Zero. Cannot navigate multi-level menus, type on software keyboards, or fill complex forms.
- **Environment:** Low-bandwidth rural connectivity; no technical support or tech-savvy family members nearby ("no one to ask").
- **Goal:** Find out if she can get monthly financial help (₹1,000/month), a free sewing machine for livelihood, or maternity nutrition aid, and learn the exact physical steps and documents needed to apply.

---

## 🌟 2. Solution Overview

**மகளிர் அரசு நலத்திட்டங்கள்** is a touch-first, voice-guided web application built with **Streamlit**, **Google Gemini 3.8 Flash**, and **Google Text-to-Speech (gTTS)**. Designed specifically for zero-literacy and low-digital-confidence rural women:
- Presents **exactly 4 large touch buttons** (1 demo button + 3 real government scheme buttons) with distinct icons, color coding, and pure Tamil labels.
- A single tap triggers an empathetic, plain-language explanation generated by Gemini 3.8 Flash formatted into 3 clear headings: 1) What the scheme is, 2) Who is eligible, and 3) 2–3 physical application steps with required documents.
- Explanations are **spoken aloud automatically in Tamil** using gTTS audio, with a **`🔁 மறுபடியும் கேளுங்கள்` (Listen Again)** button that replays cached audio instantly with zero API calls.
- Includes an **instant offline demo button** requiring no internet or credentials, plus a warm, friendly offline fallback that directs the user to their local village Ration Shop or *e-Sevai* center.

## 📋 3. Features Mapped to the Problem Statement

| Problem Statement Requirement | Application Feature | How It Directly Solves the Challenge |
|---|---|---|
| *"Zero prior digital knowledge"* | **4 Large High-Contrast Touch Buttons (92px+ min-height)** | No typing, search boxes, hamburger menus, or navigation bars required. One tap directly opens the service. |
| *"No English"* | **100% Tamil User Interface (Pure Spoken Tamil)** | Zero English words anywhere in user-facing UI; uses colloquial, respectful spoken vocabulary (`அம்மா, ...`). |
| *"No tech background"* | **Clearly Bordered Visual Cards + Emojis** | Visual icons (💰, 🧵, 👶, ✨) pair with bold 23px+ typography so users can operate the tool even with limited reading ability. |
| *"No one to ask"* | **Automatic Voice Playback (gTTS Audio)** | The app speaks the explanation aloud automatically, acting as a patient personal village counselor in her pocket. |
| *"Audio re-listening without latency"* | **`🔁 மறுபடியும் கேளுங்கள்` (Cached Audio Replay)** | Replays the cached audio buffer in session state immediately without re-calling Gemini or gTTS. |
| *"Network fragility & no credentials"* | **Instant Offline Demo Mode (`✨ மாதிரி விளக்கம்`)** | Pre-written verified explanation and audio loads instantly with zero API calls and zero network latency. |
| *"Unreliable rural internet"* | **Empathetic Village Help Fallback** | Never shows raw tracebacks or HTTP error codes. Guides the woman to her local Ration Shop or *e-Sevai* center. |

## 🏛️ 4. The 3 Government Schemes Included

1. **💰 கலைஞர் மகளிர் உரிமைத் திட்டம் (Kalaignar Magalir Urimai Thittam)**
   - *Category:* Direct Financial Assistance
   - *Benefit:* ₹1,000 monthly deposited directly into the woman head of household's bank account.
2. **🧵 இலவச தையல் இயந்திரம் வழங்கும் திட்டம் (Sathiyavani Muthu Free Sewing Machine Scheme)**
   - *Category:* Livelihood & Self-Employment
   - *Benefit:* Free sewing machine for poor women, widows, and deserted wives to start home tailoring.
3. **👶 பிரதம மந்திரி மாத்ரு வந்தனா திட்டம் (PMMVY - Maternity Benefit)**
   - *Category:* Mother & Child Health
   - *Benefit:* ₹5,000 cash incentive for pregnant and lactating mothers for health checks and nutrition.

## 🛠️ 5. Tech Stack

- **Language & Runtime:** Python 3.10+
- **Frontend Framework:** [Streamlit](https://streamlit.io/) (Kiosk-style custom CSS, responsive layout)
- **Core AI Model:** [Google Gemini 3.8 Flash](https://ai.google.dev/) via official `google-genai` SDK
- **Voice Synthesis:** [gTTS (Google Text-to-Speech)](https://pypi.org/project/gTTS/) + HTML5 Web Speech API fallback
- **Containerization & Cloud Hosting:** Docker + [Google Cloud Run](https://cloud.google.com/run)
- **Environment Management:** `python-dotenv` for secure environment variable handling
- **Testing Framework:** `pytest` + `streamlit.testing.v1.AppTest`

## 🤖 6. How Google Antigravity Was Used

This application was engineered and refined using **Google Antigravity**:
1. **Persona & UX Synthesis:** Synthesized WCAG AAA high-contrast design tokens, large touch card heights (92px+), and spoken rural Tamil phrasing suitable for first-time smartphone users.
2. **Architecture Separation:** Enforced strict separation between UI rendering (`app.py`) and AI/audio business logic (`utils.py`).
3. **Prompt Iteration & Fallback Containment:** Developed prompt templates for Gemini 3.8 Flash that enforce structured 3-part responses without bureaucratic jargon, accompanied by robust exception containment.
4. **Automated Verification:** Authored and ran a 14-test suite via `pytest` covering API failure modes, missing keys, empty payloads, gTTS synthesis, audio caching, and headless Streamlit click events.

## 🚀 8. Setup & Run Instructions (Local)

### 1. Clone the repository:
```bash
git clone <repo-url>
cd promt-wars-app
```

### 2. Activate virtual environment:
```bash
# Windows
.\.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate
```

### 3. Install production dependencies:
```bash
pip install -r requirements.txt
```

### 4. Configure Gemini API Key:
Create a `.env` file in the project root:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```
*(Note: The app works in instant Offline Demo Mode even without an API key!)*

### 5. Run the application:
```bash
streamlit run app.py
```
Open `http://localhost:8501` in your browser.

### 6. Run automated test suite:
```bash
pytest -v
```

## ☁️ 9. Deployment

This app is deployed on **Google Cloud Run**, a fully managed serverless platform, as required by the PromptWars x HackArena event rules.

**Why Cloud Run:**
- Automatically scales to zero when idle and scales up under load — no server management needed
- Deploys directly from our GitHub repository via Cloud Build, using the included Dockerfile
- Provides a public HTTPS endpoint with no authentication required, so evaluators can access the app instantly

**Google services used in this project:**
1. **Gemini API** — powers the core AI feature: generating simple, spoken-style Tamil explanations of government schemes
2. **Google Cloud Run** — hosts and serves the deployed application
3. **Google Text-to-Speech (via gTTS)** — converts Gemini's Tamil responses into spoken audio for the voice-first experience

**Deployment process:**

3. Container deployed to Cloud Run in the `asia-south1` (Mumbai) region
4. Environment variable `GEMINI_API_KEY` set securely via Cloud Run's Variables & Secrets (never hardcoded)
5. Public access enabled so the app works with zero login

## 📝 10. Note on Descoped Features

- **Live Microphone Audio Follow-Up (`st.audio_input`):**  
  An optional conversational voice-recording follow-up feature was explored during development. However, after user-testing and considering the target persona (a first-time rural woman user with zero digital experience), microphone permission dialogs, audio codec variance across low-end Android browsers, and background noise in village environments introduced points of failure. In accordance with the project rule (*"a working simple app beats a broken ambitious one"*), live audio recording was cleanly descoped in favor of the rock-solid, zero-friction 4-button touch-and-listen interface.
